Currently in progress of developing a program that asks a user for a start date, end date, and their API key. Using this information, the program pulls data from NASA's NeoWs API which will then be used to calculate a mission feasbility score. I am using this project as my final project for CS50 Introduction to Programming with Python.

Planned Feasibility Score calculation (subject to change): Score = (Diameter)/(Miss Distance)*(Velocity)*(Sin(Inclination))

I hope to later add in more complex calculations, but I want to initially start out with some easier variables to work with to get a better understanding of how my code can become more accurate. As I do more research I will add in sources and more closely refine my code.
